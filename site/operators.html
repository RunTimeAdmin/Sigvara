Operators

Scores are proposed by bonded oracle operators. Each one posts a bond the slashing committee can take, names the key it signs with, and runs in public: anyone can read when it last ran and what code it runs. A second operator, the checker, recomputes every pending score and publishes any disagreement while the committee can still act on it.

Arc testnet (5042002). Reads only. Bonds and signers come from the bond contract and Sigvara's event index of it, with the newest blocks read from the chain; each operator's last proposal from the index and the chain; health from each operator's own endpoint.
