Contact

Sigvara is an open-source project. Here is how to reach the people who run it.

Questions

Write to support@sigvara.xyz about the protocol, an integration, this site, or data we may hold about you.

Security problems

Report a bug in the contracts, the oracle or this site privately, to security@sigvara.xyz or through GitHub's private vulnerability reporting. Please do not open a public issue for it. The security policy says what is in scope and how reports are handled.

In public

For anything that can be public, open an issue on GitHub. News goes out on X as @SigvaraProtocol.

To integrate a score, run an operator or test the protocol, see Get involved.
